# hece-engine

Local Whisper speech-to-text for Hece, without Python: a Rust port of faster-whisper 1.2.1's
pipeline (log-mel, Silero VAD, timestamp-segment decoding with temperature fallback) on top of
CTranslate2 through [`ct2rs`](https://github.com/jkawamoto/ctranslate2-rs). See `THIRD_PARTY.md`.

Everything except the CTranslate2 call is plain Rust and is built and tested in CI without CUDA.

## Features

| Feature | What it does |
| --- | --- |
| *(none)* | Mel, VAD, tokenizer and decode logic; the binary exits with `built_without_cuda` |
| `cuda` | Links CTranslate2 with CUDA, cuBLAS statically linked |
| `cuda-dynamic` | Same, but CUDA libraries are loaded at runtime from the system (`cuda-dynamic-loading`) |

ct2rs' `whisper`/`sentencepiece` features stay off: sentencepiece's bundled protobuf clashes with
`ort` at link time, and we use the `tokenizers` crate instead.

## Building

Prerequisites: CUDA toolkit, gcc, cmake.

```sh
CUDA_ARCH_LIST="8.9;12.0" cargo build --release -p hece-engine --features cuda-dynamic
```

- `CUDA_ARCH_LIST="8.9;12.0"` covers Ada and Blackwell (sm_120) and builds cleanly with CUDA 13.4.
  Add your GPU's compute capability if it is older.
- The CTranslate2 C++ build is memory hungry. On a 16 GB machine limit parallelism and never run
  two CUDA builds at once: `CMAKE_BUILD_PARALLEL_LEVEL=4 CARGO_BUILD_JOBS=4`.

## CUDA distribution decision

Measured on Arch Linux, CUDA 13.4, RTX 5050 Laptop (8 GB), `examples/transcribe_dir` in release:

| Variant | Binary size | CUDA libs at runtime | Runs | 1.5 s clip incl. cold model load | Max RSS |
| --- | --- | --- | --- | --- | --- |
| `cuda` (static cuBLAS) | 576 MB | none (static) | yes | — | — |
| `cuda-dynamic` | 37 MB | `libcublas.so.13`, `libcublasLt.so.13`, driver `libcuda.so.1` (dlopen) | yes | 7.0 s | 3.2 GB |

**Decision:** packages use `cuda-dynamic` and declare the distribution's CUDA runtime (cuBLAS 13) as
a dependency; on Arch that is the `cuda` package. The static build is kept for self-contained
binaries. The engine runs as an on-demand worker process, so the RSS above is only held while a
model is loaded.

## Tests

```sh
cargo test -p hece-engine                       # CI set, no GPU needed
HECE_TEST_MODEL_DIR=<ctranslate2 whisper dir> \
  cargo test -p hece-engine --release --features cuda-dynamic -- --include-ignored
```

The model directory must contain `model.bin`, `config.json` and `tokenizer.json` (a multilingual
Whisper model converted with `ct2-transformers-converter`). Parity fixtures under `tests/fixtures`
are generated by faster-whisper 1.2.1 itself; see `tests/fixtures/README.md`.
