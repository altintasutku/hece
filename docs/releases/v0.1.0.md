The first public release of Hece: background voice dictation for Windows. Hold
**Ctrl+Shift+Space**, speak, and the text lands in the window you are typing in.

## Install

1. Download `Hece_0.1.0_x64-setup.exe` below and run it (per-user, no administrator rights).
2. Hece Settings opens. Download a model (multilingual Whisper large-v3 turbo by default) if you
   have an NVIDIA GPU, or add a cloud provider key (OpenAI-compatible such as Groq, or Deepgram).
3. Start **Hece** from the Start menu and hold **Ctrl+Shift+Space** to dictate.

> **Unsigned build.** This release is not code-signed yet, so Windows SmartScreen may show
> "Windows protected your PC". Choose **More info → Run anyway**. You can verify the file first:
> compare it with `SHA256SUMS.txt`, or run
> `gh attestation verify Hece_0.1.0_x64-setup.exe --repo altintasutku/hece` to check that it was
> built by this repository's GitHub Actions workflow. Signing is in progress (#49).

## What's in it

- Push-to-talk and toggle modes, a recording orb that reacts to your voice, tray menu.
- Local Whisper on your NVIDIA GPU (CTranslate2), fully offline once the model is downloaded.
  The CUDA runtime is downloaded on demand from NVIDIA; models are pinned and checksummed.
- Cloud providers: OpenAI-compatible endpoints (OpenAI, Groq, self-hosted), Deepgram. Keys are
  stored in the Windows Credential Manager.
- Quality layers: personal vocabulary, a filter for text Whisper invents in silence, a
  low-confidence signal, and optional LLM cleanup with a guard that keeps negations.
- One paste chord into the focused window; transcripts stay out of Win+V clipboard history.
- Local dictation history with re-paste, and an optional local OpenAI-compatible API.
- No telemetry. Audio, transcripts and API keys are never logged.

## Known limits

- Windows x64 only for now, tested on Windows 11. Linux and macOS are planned (help wanted).
- Local transcription needs an NVIDIA GPU; otherwise use a cloud provider.
- Pasting into apps running as administrator is blocked by Windows; the text stays in the history.
